# Entretien de manager : les questions auxquelles se préparer

Un entretien pour un poste de manager ne consiste pas seulement à vérifier si vous connaissez votre métier.

Le recruteur cherche aussi à comprendre :

- comment vous prenez des décisions ;
- comment vous déléguez ;
- comment vous gérez un conflit ;
- comment vous faites progresser une équipe ;
- comment vous réagissez face à une baisse de performance ;
- comment vous arbitrez entre résultats et humain.

C’est pour cette raison que les entretiens de management comportent souvent beaucoup de questions comportementales.

Le recruteur ne veut pas seulement entendre vos principes.

Il veut des preuves.

---

## Ce que le recruteur cherche réellement chez un manager

Le manager est rarement évalué uniquement sur ses résultats individuels.

Le recruteur cherche généralement à savoir si vous êtes capable de :

- produire des résultats à travers une équipe ;
- donner un cadre ;
- décider ;
- gérer des situations difficiles ;
- faire évoluer les collaborateurs ;
- représenter les intérêts de l’organisation ;
- assumer vos arbitrages.

La question implicite est souvent :

> **Comment cette personne se comporte-t-elle quand le management devient difficile ?**

---

## 1. « Comment définiriez-vous votre style de management ? »

C’est une question très fréquente.

Évitez les réponses vagues :

> « Je suis un manager bienveillant mais exigeant. »

Cette formulation est tellement utilisée qu’elle apporte peu d’information.

Préférez expliquer :

- comment vous donnez les objectifs ;
- comment vous laissez de l’autonomie ;
- comment vous contrôlez ;
- comment vous adaptez votre approche.

### Exemple

> « Je donne beaucoup d’importance à la clarté des objectifs et au niveau d’autonomie attendu. Une fois le cadre posé, j’essaie d’éviter le micro-management, mais je maintiens des points réguliers pour identifier rapidement les difficultés. »

Puis ajoutez un exemple.

---

## 2. « Comment gérez-vous un collaborateur en difficulté ? »

Le recruteur veut comprendre votre méthode.

Une réponse solide peut suivre plusieurs étapes :

1. comprendre la cause ;
2. clarifier les attentes ;
3. définir un plan d’action ;
4. suivre l’évolution ;
5. prendre une décision si la situation ne s’améliore pas.

Évitez de répondre uniquement :

> « Je l’accompagne. »

Le recruteur veut savoir comment.

---

## 3. « Comment gérez-vous un collaborateur performant mais difficile ? »

C’est une question intéressante car elle crée un arbitrage.

Un très bon contributeur peut :

- nuire à l’équipe ;
- créer des conflits ;
- ne pas respecter certaines règles.

Le recruteur observe votre capacité à distinguer :

- performance individuelle ;
- impact collectif.

Une bonne réponse montre que la performance ne donne pas un droit permanent à dégrader le fonctionnement de l’équipe.

---

## 4. « Parlez-moi d’un conflit dans votre équipe »

Évitez de choisir une situation où le conflit était insignifiant.

Préparez un exemple qui permet de montrer :

- écoute ;
- analyse ;
- arbitrage ;
- communication ;
- décision.

La méthode STAR peut être particulièrement utile.

---

## 5. « Comment déléguez-vous ? »

Le recruteur peut chercher à savoir si vous :

- déléguez réellement ;
- contrôlez excessivement ;
- adaptez le niveau de délégation.

Une bonne réponse explique :

- ce qui peut être délégué ;
- à qui ;
- avec quel niveau d’autonomie ;
- quels points de contrôle sont nécessaires.

---

## 6. « Comment faites-vous progresser vos collaborateurs ? »

Le management ne consiste pas seulement à répartir le travail.

Préparez des exemples de :

- feedback ;
- accompagnement ;
- formation ;
- responsabilisation ;
- mobilité ;
- montée en compétence.

### Exemple

> « Lorsqu’un collaborateur souhaite évoluer, j’essaie d’identifier une responsabilité réelle qui lui permette de tester le niveau supérieur plutôt que de rester uniquement sur de la formation théorique. »

---

## 7. « Comment donnez-vous un feedback négatif ? »

Le recruteur veut comprendre si vous savez :

- être direct ;
- rester factuel ;
- éviter l’humiliation ;
- obtenir un changement.

Une structure simple :

- faits observables ;
- impact ;
- attente ;
- plan d’action.

---

## 8. « Comment prenez-vous une décision impopulaire ? »

Un manager ne peut pas chercher systématiquement le consensus.

Le recruteur veut savoir si vous êtes capable de :

- écouter ;
- décider ;
- expliquer ;
- assumer.

### Exemple

> « Je cherche à expliquer le raisonnement, les contraintes et ce qui a été pris en compte, mais une fois la décision prise, je considère que mon rôle est aussi de l’assumer clairement. »

---

## 9. « Comment gérez-vous une équipe qui n’atteint pas ses objectifs ? »

Évitez de commencer immédiatement par :

> « Je mets plus de pression. »

Commencez par comprendre :

- objectifs réalistes ?
- problème collectif ?
- compétences ?
- ressources ?
- organisation ?
- motivation ?

Puis expliquez votre plan.

---

## 10. « Comment gérez-vous les priorités contradictoires ? »

Un manager reçoit souvent des demandes concurrentes.

Le recruteur veut comprendre votre capacité à :

- hiérarchiser ;
- arbitrer ;
- dire non ;
- expliquer les compromis.

Préparez un exemple concret.

---

## 11. « Que faites-vous lorsqu’un collaborateur n’est pas d’accord avec vous ? »

Une opposition n’est pas forcément un problème.

Une bonne réponse peut montrer que vous :

- écoutez les arguments ;
- acceptez d’être challengé ;
- distinguez débat et décision ;
- tranchez si nécessaire.

---

## 12. « Comment gérez-vous un conflit entre deux collaborateurs ? »

Le risque est d’intervenir trop vite en apportant vous-même la solution.

Une bonne approche consiste souvent à :

- comprendre les faits ;
- faire exprimer les perceptions ;
- clarifier les responsabilités ;
- reconstruire un mode de fonctionnement.

---

## 13. « Avez-vous déjà dû recadrer quelqu’un ? »

Préparez un exemple réel.

Le recruteur cherche à savoir si vous :

- évitez les conversations difficiles ;
- savez être explicite ;
- documentez les attentes ;
- suivez les progrès.

---

## 14. « Avez-vous déjà dû prendre une décision concernant un collaborateur qui ne progressait pas ? »

Cette question teste votre capacité à gérer le management dans sa dimension la moins confortable.

Ne cherchez pas à paraître dur.

Ne cherchez pas non plus à montrer que vous évitez toute décision difficile.

Expliquez le processus.

---

## 15. « Comment motivez-vous votre équipe ? »

Attention à la réponse :

> « Je motive mes équipes. »

La motivation est rarement un bouton sur lequel le manager appuie.

Vous pouvez plutôt parler de :

- clarté ;
- autonomie ;
- reconnaissance ;
- progression ;
- sens ;
- responsabilisation.

---

## 16. « Comment gérez-vous les différences de niveau dans une équipe ? »

Le recruteur observe votre capacité à adapter votre management.

Un collaborateur très autonome n’a pas besoin du même niveau de suivi qu’un débutant.

Expliquez comment vous adaptez :

- fréquence des points ;
- niveau de contrôle ;
- délégation ;
- accompagnement.

---

## 17. « Quel a été votre plus grand échec comme manager ? »

Ne donnez pas une réussite déguisée.

Choisissez une situation qui montre :

- erreur réelle ;
- impact ;
- prise de responsabilité ;
- apprentissage.

### Exemple

> « J’ai promu trop rapidement un excellent expert sur une fonction de management sans suffisamment l’accompagner. La transition a été difficile pour lui et pour l’équipe. Depuis, je prépare davantage ce type de prise de poste et je mets en place un accompagnement beaucoup plus structuré. »

---

## 18. « Qu’attendez-vous de votre propre manager ? »

Le recruteur cherche aussi à comprendre votre relation à la hiérarchie.

Une réponse équilibrée peut évoquer :

- clarté des priorités ;
- confiance ;
- capacité d’arbitrage ;
- feedback ;
- autonomie.

---

## Les erreurs fréquentes des candidats managers

### Ne parler que de bienveillance

Le management comporte aussi :

- décisions ;
- exigence ;
- arbitrages ;
- recadrage.

### Ne parler que de performance

Un manager qui ne parle jamais de développement des collaborateurs peut sembler très opérationnel mais peu managérial.

### Répondre en théorie

Les grandes déclarations sur le leadership sont moins utiles que les situations vécues.

### Toujours raconter des réussites

Les difficultés donnent souvent beaucoup plus d’informations au recruteur.

## 19. Préparez un portefeuille de huit situations managériales

Avant l’entretien, préparez au minimum :

1. collaborateur en difficulté ;
2. conflit ;
3. décision impopulaire ;
4. baisse de performance ;
5. développement d’un collaborateur ;
6. délégation ;
7. transformation ;
8. erreur managériale.

Ces huit exemples permettent de couvrir une grande partie des questions.

---

## 20. Construisez votre matrice de management

Créez un tableau.

| Situation | Votre action | Résultat | Compétence |
|---|---|---|---|
| Conflit équipe | Médiation + nouvel arbitrage | Retour à la coopération | Gestion conflit |
| Baisse performance | Diagnostic + plan 30 jours | Objectifs retrouvés | Performance |
| Junior prometteur | Délégation progressive | Promotion | Développement |
| Réorganisation | Nouvelle répartition | Productivité +15 % | Transformation |

Cette matrice facilite énormément la préparation.

---

## 21. Faites apparaître vos arbitrages

Les réponses managériales deviennent intéressantes lorsqu’elles montrent que vous avez dû choisir.

Par exemple :

> performance individuelle ou cohésion ?

> vitesse ou consultation ?

> autonomie ou contrôle ?

> accompagnement ou décision ?

Expliquez :

- les options ;
- les critères ;
- votre décision ;
- les conséquences.

C’est souvent plus révélateur que la simple description du résultat.

---

## 22. Préparez une situation où vous avez changé d’avis

Un bon manager n’est pas quelqu’un qui a toujours raison.

Préparez une situation où :

- un collaborateur vous a convaincu ;
- de nouvelles données sont apparues ;
- votre première hypothèse était mauvaise.

Cette situation peut montrer :

- écoute ;
- recul ;
- absence d’ego.

---

## 23. Préparez une situation de sous-performance

Le recruteur peut vous demander :

> « Que faites-vous si un collaborateur n’atteint pas ses objectifs ? »

Préparez un vrai exemple.

Votre réponse doit permettre de comprendre :

- comment vous diagnostiquez ;
- comment vous accompagnez ;
- quel délai vous laissez ;
- quand vous changez de stratégie.

---

## 24. Préparez une situation de haut potentiel

Le management ne concerne pas uniquement les problèmes.

Le recruteur peut demander :

> « Comment gérez-vous vos meilleurs collaborateurs ? »

Préparez un exemple de :

- délégation ;
- responsabilisation ;
- évolution ;
- exposition.

---

## 25. Préparez une situation de transformation

Pour les postes de management plus expérimentés, préparez une situation où vous avez dû :

- changer une organisation ;
- modifier des processus ;
- faire évoluer des comportements ;
- gérer une résistance.

Le recruteur cherchera autant le résultat que la manière dont vous avez obtenu l’adhésion.

---

## 26. Manager de managers : changez de niveau de réponse

Si vous postulez à un poste de manager de managers, votre discours doit évoluer.

Ne parlez pas uniquement de :

> « comment je gère chaque collaborateur ».

Parlez aussi de :

- management indirect ;
- responsabilisation des managers ;
- gouvernance ;
- indicateurs ;
- arbitrages ;
- culture managériale.

---

## 27. Préparez votre philosophie managériale en trois principes

Vous devez être capable de résumer votre approche.

Par exemple :

### Clarté

Les collaborateurs doivent savoir ce qui est attendu.

### Autonomie

Le niveau de responsabilité doit être explicite.

### Feedback

Les difficultés ne doivent pas attendre l’entretien annuel.

Ces principes doivent ensuite pouvoir être illustrés par des exemples.

---

## 28. Le test de cohérence

Votre discours doit être cohérent.

Si vous dites :

> « Je donne beaucoup d’autonomie »

mais que vos exemples montrent que vous contrôlez chaque détail, le recruteur le verra.

Vérifiez que vos histoires correspondent réellement à votre discours managérial.

---

## 29. Questions à poser pour un poste de manager

Préparez notamment :

> Quel est le niveau d’autonomie de l’équipe ?

> Quelle est la principale difficulté actuelle ?

> Quel est le niveau de maturité managériale ?

> Qu’attendez-vous du futur manager dans les six premiers mois ?

> Y a-t-il des changements organisationnels prévus ?

> Quels indicateurs sont utilisés pour mesurer la performance ?

Ces questions vous permettent aussi d’évaluer le poste.

## En résumé

Pour préparer un entretien de manager, ne vous contentez pas de réfléchir à votre « style de management ».

Préparez des situations concrètes sur :

1. la délégation ;
2. le conflit ;
3. la sous-performance ;
4. le feedback ;
5. la décision difficile ;
6. le développement des collaborateurs ;
7. la transformation ;
8. vos propres erreurs.

Un recruteur ne cherche pas seulement un candidat qui connaît les principes du management.

Il cherche quelqu’un capable de montrer **comment il manage lorsque la situation devient réellement complexe**.
