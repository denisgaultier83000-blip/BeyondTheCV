# Comment se renseigner sur une entreprise avant un entretien

« Que savez-vous de notre entreprise ? »

La question paraît simple.

Pourtant, beaucoup de candidats répondent avec une succession de faits :

> « Vous avez été créés en 1985, vous êtes présents dans 12 pays et vous réalisez 800 millions d’euros de chiffre d’affaires. »

Tout cela peut être exact.

Mais ce n’est pas nécessairement utile.

Se renseigner sur une entreprise avant un entretien ne consiste pas à mémoriser sa fiche d’identité.

L’objectif est plutôt de comprendre :

- ce qu’elle fait ;
- comment elle gagne de l’argent ;
- sur quel marché elle évolue ;
- ce qui semble important pour elle aujourd’hui ;
- quels défis peuvent concerner le poste visé.

Une bonne recherche vous permet ensuite de mieux répondre, mais aussi de poser de meilleures questions.

---

## Ce que le recruteur cherche réellement

Lorsqu’un recruteur vérifie votre connaissance de l’entreprise, il peut chercher plusieurs choses :

- avez-vous préparé l’entretien ?
- comprenez-vous notre activité ?
- votre motivation est-elle spécifique ?
- savez-vous relier votre expérience à notre contexte ?
- avez-vous réfléchi au poste au-delà de son intitulé ?

Le but n’est donc pas de réciter des informations.

Il est de montrer que vous les avez comprises.

---

## 1. Commencez par comprendre ce que vend réellement l’entreprise

Cela semble évident.

Pourtant, certaines entreprises ont une activité plus complexe qu’il n’y paraît.

Cherchez à comprendre :

- produits ;
- services ;
- clients ;
- secteurs ;
- zones géographiques ;
- principales sources de revenus.

Posez-vous une question simple :

> **Si je devais expliquer en deux phrases comment cette entreprise gagne de l’argent, serais-je capable de le faire ?**

Si la réponse est non, poursuivez votre recherche.

---

## 2. Identifiez ses clients

Une entreprise B2B qui vend à de grands groupes n’a pas les mêmes contraintes qu’une entreprise B2C.

Essayez d’identifier :

- type de clientèle ;
- taille des clients ;
- secteurs servis ;
- dépendance éventuelle à quelques grands comptes ;
- présence publique ou privée.

Cela peut être particulièrement important pour des fonctions :

- commerciales ;
- marketing ;
- produit ;
- stratégie ;
- opérations.

---

## 3. Comprenez son marché

Vous n’avez pas besoin de devenir analyste sectoriel.

Mais vous devez connaître les grandes lignes.

Cherchez notamment :

- principaux concurrents ;
- évolution du marché ;
- facteurs de croissance ;
- contraintes réglementaires ;
- évolutions technologiques ;
- nouveaux usages.

L’objectif est de comprendre dans quel environnement l’entreprise prend ses décisions.

---

## 4. Regardez son actualité récente

L’actualité peut donner des indices précieux.

Cherchez les événements des derniers mois :

- acquisition ;
- fusion ;
- lancement de produit ;
- ouverture d’un marché ;
- changement de direction ;
- plan d’investissement ;
- restructuration ;
- résultats ;
- partenariat ;
- recrutement important.

Une actualité récente peut avoir un lien direct avec le poste.

---

## 5. Commencez par les sources de l’entreprise

Les sources officielles sont utiles pour comprendre ce que l’entreprise choisit de communiquer.

Consultez notamment :

- site institutionnel ;
- page carrière ;
- communiqués ;
- rapport annuel ;
- rapport RSE ;
- présentations investisseurs ;
- offres d’emploi ;
- publications LinkedIn officielles.

Attention toutefois :

> une entreprise parle d’elle-même avec son propre angle.

Ces sources sont indispensables, mais elles ne suffisent pas toujours.

---

## 6. Croisez avec des sources externes

Pour éviter une vision uniquement institutionnelle, recherchez également :

- presse économique ;
- presse sectorielle ;
- interviews de dirigeants ;
- publications professionnelles ;
- rapports de marché ;
- données publiques ;
- comptes publiés lorsqu’ils sont accessibles.

L’objectif est de comparer plusieurs sources.

Une information répétée dans différentes sources est généralement plus solide qu’une affirmation isolée.

---

## 7. Regardez comment l’entreprise se décrit lorsqu’elle recrute

Les offres d’emploi peuvent être particulièrement instructives.

Même celles qui ne concernent pas votre poste.

Observez :

- vocabulaire ;
- compétences recherchées ;
- croissance des équipes ;
- métiers recrutés ;
- implantation géographique ;
- technologies utilisées.

Une entreprise qui recrute massivement dans un domaine envoie souvent un signal sur ses priorités.

---

## 8. Analysez les concurrents

Vous n’avez pas besoin de connaître toute l’industrie.

Identifiez quelques concurrents principaux.

Puis posez-vous :

- comment l’entreprise se différencie-t-elle ?
- prix ?
- technologie ?
- service ?
- spécialisation ?
- image de marque ?
- réseau de distribution ?

Comprendre cette différence peut enrichir considérablement votre entretien.

---

## 9. Cherchez les enjeux qui pourraient affecter votre poste

C’est probablement l’étape la plus importante.

Ne restez pas au niveau de l’entreprise entière.

Revenez au poste.

### Exemple

Vous postulez comme responsable commercial.

L’entreprise vient d’ouvrir deux nouveaux marchés.

Question à préparer :

> Comment développer le portefeuille sur ces nouvelles zones ?

Vous postulez comme DSI.

L’entreprise vient de réaliser plusieurs acquisitions.

Enjeu possible :

> intégration des systèmes et harmonisation des outils.

Vous postulez en ressources humaines.

L’entreprise recrute massivement.

Enjeu possible :

> attractivité, intégration ou structuration RH.

Vous transformez ainsi une information générale en sujet professionnel.

---

## 10. Ne confondez pas information et hypothèse

C’est un point essentiel.

Vous lisez :

> l’entreprise a acquis trois concurrents en deux ans.

C’est un fait.

Vous en déduisez :

> elle doit avoir de gros problèmes d’intégration.

C’est une hypothèse.

Ne présentez jamais l’hypothèse comme une certitude.

Préférez :

> « J’ai vu que vous aviez réalisé plusieurs acquisitions récemment. Est-ce que l’intégration des différentes organisations constitue un enjeu important pour ce poste ? »

Vous montrez votre réflexion sans prétendre connaître l’entreprise de l’intérieur.

---

## 11. Renseignez-vous sur la culture, mais restez prudent

Le mot « culture » est souvent utilisé de manière très vague.

Vous pouvez chercher des indices :

- style de communication ;
- organisation ;
- valeurs affichées ;
- niveau de formalisation ;
- politique managériale ;
- fonctionnement des équipes.

Mais évitez de conclure trop vite.

Une page carrière qui affirme :

> « Ici, chacun peut être lui-même »

ne suffit évidemment pas à démontrer toute la culture d’une organisation.

Traitez les informations comme des indices à vérifier pendant l’entretien.

---

## 12. Étudiant ou jeune diplômé : concentrez-vous sur l’essentiel

Vous n’avez pas besoin d’arriver avec une analyse stratégique de 50 pages.

Préparez au minimum :

- activité ;
- principaux produits ou services ;
- clients ;
- actualité récente ;
- raison pour laquelle l’entreprise vous intéresse.

Puis identifiez une information spécifique que vous pourrez utiliser.

### Exemple

> « J’ai vu que vous développiez actuellement votre activité sur les solutions de cybersécurité pour PME. C’est particulièrement intéressant pour moi car c’est un sujet que j’ai travaillé pendant mon alternance. »

---

## 13. Cadre ou manager : allez plus loin dans les enjeux

Pour des postes plus expérimentés, une connaissance superficielle sera moins convaincante.

Essayez de comprendre :

- stratégie ;
- organisation ;
- position concurrentielle ;
- transformations ;
- difficultés potentielles ;
- enjeux du périmètre.

Le but n’est toujours pas de jouer au consultant.

Il est de comprendre le contexte dans lequel vous pourriez travailler.

---

## 14. Dirigeant : analysez également les résultats et la gouvernance

Pour un poste de direction, la recherche peut inclure :

- résultats financiers ;
- trajectoire de croissance ;
- acquisitions ;
- gouvernance ;
- actionnariat ;
- investissements ;
- priorités annoncées ;
- principaux risques.

Votre niveau de préparation doit correspondre au niveau du poste.

---

## 15. Construisez une fiche entreprise d’une page

Avant l’entretien, résumez vos recherches.

### Activité

Que fait l’entreprise ?

### Clients

À qui vend-elle ?

### Marché

Quels sont les principaux enjeux ?

### Concurrents

Qui sont-ils ?

### Actualité

Quels événements récents sont importants ?

### Poste

Quel lien avec la fonction visée ?

### Questions

Que souhaitez-vous vérifier ?

Une page suffit généralement.

## 16. Transformez chaque information en une question ou un argument

C’est là que la recherche devient réellement utile.

Prenez une information :

> L’entreprise développe fortement son activité à l’international.

Vous pouvez la transformer en :

### Question

> « Quels marchés constituent aujourd’hui les principales priorités de développement ? »

### Argument

> « Mon expérience de coordination d’équipes internationales pourrait être particulièrement utile dans ce contexte. »

Une information qui ne produit ni question ni argument est souvent secondaire pour votre entretien.

---

## 17. Utilisez la matrice Fait – Hypothèse – Question – Argument

Pour structurer votre recherche :

| Fait observé | Hypothèse | Question à poser | Argument personnel |
|---|---|---|---|
| 3 acquisitions récentes | Intégration importante | Quels sont les principaux enjeux d’intégration ? | Expérience fusion SI |
| Croissance internationale | Structuration nécessaire | Quels marchés sont prioritaires ? | Management multiculturel |
| Recrutements commerciaux | Développement accéléré | Comment est organisée la force de vente ? | Structuration commerciale |

Cette matrice évite deux erreurs :

- accumuler des informations inutiles ;
- prendre vos hypothèses pour des faits.

---

## 18. Recherchez les signaux de transformation

Certains événements peuvent annoncer des changements :

- nouveau dirigeant ;
- acquisition ;
- levée de fonds ;
- réorganisation ;
- nouveau marché ;
- transformation numérique ;
- évolution réglementaire.

Ces signaux sont intéressants lorsqu’ils peuvent être reliés au poste.

---

## 19. Recherchez aussi les signaux de difficulté

Avec prudence, regardez :

- baisse d’activité ;
- pertes ;
- restructurations ;
- départs de dirigeants ;
- fermeture de sites ;
- difficultés sectorielles.

Il ne s’agit pas de mener un interrogatoire pendant l’entretien.

Mais vous devez savoir dans quel contexte vous candidatez.

---

## 20. Préparez trois niveaux d’information

Toutes vos recherches n’ont pas la même importance.

### Niveau 1 — indispensable

- activité ;
- poste ;
- marché ;
- actualité principale.

### Niveau 2 — utile

- concurrence ;
- stratégie ;
- culture ;
- organisation.

### Niveau 3 — approfondissement

- résultats détaillés ;
- acquisitions ;
- gouvernance ;
- données sectorielles.

Adaptez le niveau au poste et au temps disponible.

---

## 21. Faites attention aux données anciennes

Une page internet peut rester visible plusieurs années.

Vérifiez toujours :

- date ;
- contexte ;
- source.

Une stratégie annoncée il y a quatre ans peut ne plus être actuelle.

---

## 22. Évitez les avis isolés

Vous pouvez trouver des témoignages sur :

- Glassdoor ;
- forums ;
- réseaux sociaux ;
- commentaires.

Ils peuvent apporter des pistes.

Mais un avis individuel ne décrit pas nécessairement toute l’entreprise.

Utilisez-le comme :

> un signal à recouper,

pas comme :

> une vérité.

---

## 23. Préparez votre réponse à « Pourquoi notre entreprise ? »

Votre recherche doit vous permettre d’éviter :

> « Parce que vous êtes un acteur reconnu. »

Préparez plutôt deux ou trois raisons spécifiques.

Exemple :

> « Deux éléments m’intéressent particulièrement : votre développement sur le marché européen et la transformation actuelle de votre offre B2B. Mon parcours comporte justement ces deux dimensions. »

---

## 24. Préparez cinq questions spécifiques

Après votre recherche, vous devriez pouvoir poser des questions impossibles à préparer sans connaître l’entreprise.

Par exemple :

> Vous avez récemment ouvert deux nouveaux marchés. Comment cela modifie-t-il les priorités de l’équipe ?

> Vous avez annoncé une transformation de votre organisation commerciale. Où en êtes-vous aujourd’hui ?

> La croissance semble importante sur votre activité B2B. Quels sont les principaux freins aujourd’hui ?

Ces questions démontrent une vraie préparation.

---

## 25. Faites le test des deux minutes

Avant l’entretien, essayez de répondre à :

> « Que savez-vous de notre entreprise ? »

en deux minutes maximum.

Votre réponse ne doit pas être une liste de faits.

Elle doit montrer :

- activité ;
- contexte ;
- raison de votre intérêt.

---

## 26. Ne cherchez pas à impressionner avec des informations confidentielles

Évitez les tentatives du type :

> « J’ai entendu dire que votre directeur allait partir… »

Vous n’avez rien à gagner à jouer au renseignement privé.

Utilisez des informations :

- publiques ;
- pertinentes ;
- vérifiables.

---

## 27. Une bonne recherche doit aussi pouvoir vous faire renoncer

La préparation ne sert pas seulement à décrocher le poste.

Vous pouvez découvrir :

- secteur qui ne vous intéresse pas ;
- stratégie incompatible avec vos attentes ;
- situation financière difficile ;
- niveau de responsabilité différent de ce que vous imaginiez.

C’est utile.

Vous évaluez aussi l’entreprise.

---

## 28. Votre checklist entreprise

Avant l’entretien :

- [ ] Je sais expliquer l’activité en deux phrases.
- [ ] Je connais les principaux clients ou marchés.
- [ ] J’ai identifié quelques concurrents.
- [ ] J’ai consulté l’actualité récente.
- [ ] Je comprends les grands enjeux.
- [ ] J’ai relié ces enjeux au poste.
- [ ] J’ai distingué faits et hypothèses.
- [ ] J’ai préparé trois questions spécifiques.
- [ ] Je sais expliquer pourquoi l’entreprise m’intéresse.

## En résumé

Pour vous renseigner efficacement sur une entreprise :

1. comprenez son activité ;
2. identifiez ses clients ;
3. regardez son marché ;
4. consultez son actualité ;
5. croisez les sources officielles et externes ;
6. analysez ses concurrents ;
7. cherchez les enjeux liés au poste ;
8. distinguez faits et hypothèses ;
9. transformez les informations en questions ;
10. reliez-les à votre propre expérience.

Une bonne préparation ne consiste pas à connaître davantage d’informations que le recruteur.

Elle consiste à savoir **lesquelles sont utiles pour comprendre le poste et défendre votre candidature**.
