Un entretien dans une semaine : plan de préparation jour par jour

Votre entretien est dans sept jours.

Bonne nouvelle :

vous avez largement le temps.

À une condition :

ne pas passer six jours à lire des conseils avant de commencer réellement à vous entraîner.

Une bonne préparation suit une progression :

comprendre → sélectionner → construire → s’entraîner → simplifier.

Voici un programme sur sept jours.

J-7 — Comprendre le poste

Commencez par l’annonce.

Identifiez :

cinq responsabilités principales ;

trois compétences prioritaires ;

niveau d’expérience attendu ;

principales contraintes ;

éléments que vous devez clarifier.

Posez-vous :

Quel problème l’entreprise essaie-t-elle probablement de résoudre avec ce recrutement ?

Travail du jour

Créez une feuille avec trois colonnes :

Attente

Preuve dans mon parcours

Écart

Management

Équipe de 8 personnes

Taille plus faible

Développement B2B

5 ans d’expérience

Aucun

Anglais

B2 professionnel

À travailler à l’oral

Vous avez désormais votre carte de préparation.

J-6 — Comprendre l’entreprise

Travaillez :

activité ;

clients ;

marché ;

actualité ;

concurrents ;

stratégie visible.

L’objectif n’est pas d’apprendre le site par cœur.

Vous cherchez ce qui permet de mieux comprendre le poste.

Préparez trois questions

Exemple :

« Quelle est aujourd’hui la priorité principale de cette fonction ? »

« Pourquoi le poste est-il ouvert ? »

« Qu’attendez-vous de la personne recrutée après six mois ? »

J-5 — Sélectionner vos preuves

Choisissez vos meilleures expériences.

Préparez notamment :

réussite ;

difficulté ;

conflit ;

erreur ;

initiative ;

projet ;

changement.

Pour chacune :

contexte ;

problème ;

votre action ;

résultat.

J-4 — Construire votre discours

Préparez :

Votre pitch

60 à 90 secondes.

Pourquoi ce poste ?

Trois raisons maximum.

Pourquoi cette entreprise ?

Éléments spécifiques.

Vos forces

Trois preuves.

Vos écarts

Réponse factuelle.

Vous disposez maintenant de l’ossature de l’entretien.

J-3 — Préparer les questions probables

Listez :

questions classiques ;

questions liées au poste ;

questions liées à votre CV ;

objections possibles.

Ne préparez pas des textes.

Préparez des idées.

J-2 — Faire une vraie simulation

Aujourd’hui, arrêtez la préparation théorique.

Faites un entretien complet.

En conditions réalistes.

Avec :

introduction ;

questions ;

relances ;

questions difficiles ;

vos propres questions.

Enregistrez-vous si possible.

J-1 — Simplifier

La veille n’est pas le moment d’ajouter vingt nouvelles réponses.

Révisez :

pitch ;

trois messages ;

exemples ;

questions ;

logistique.

Puis arrêtez.

Jour J — Exécuter, pas réviser

Avant l’entretien, relisez une seule page.

Pas trente notes.

Vous devez avoir :

trois messages ;

quelques exemples ;

vos questions ;

les informations logistiques.
