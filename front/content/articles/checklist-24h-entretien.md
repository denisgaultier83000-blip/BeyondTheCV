# Entretien d’embauche : la checklist des 24 heures précédentes

La veille d’un entretien, beaucoup de candidats font la même erreur :

ils essaient encore d’apprendre.

Ils relisent l’annonce.

Ils cherchent de nouvelles informations sur l’entreprise.

Ils préparent une dixième version de leur pitch.

Ils ajoutent encore des questions.

À ce stade, ce n’est généralement plus ce qui apporte le plus de valeur.

Dans les 24 heures précédant l’entretien, l’objectif change.

Il faut surtout :

- sécuriser l’essentiel ;
- vérifier la logistique ;
- réduire les imprévus ;
- consolider les messages clés ;
- éviter de saturer votre attention.

La dernière journée doit servir à **stabiliser votre préparation**, pas à la reconstruire.

---

## 1. Relisez l’annonce une dernière fois

Pas pour tout réanalyser.

Simplement pour vérifier :

- les missions principales ;
- les compétences attendues ;
- les responsabilités ;
- les mots-clés du poste ;
- les points qui pourraient donner lieu à des questions.

Votre objectif est de garder une vision claire de ce que l’entreprise recherche.

---

## 2. Identifiez vos trois messages principaux

À la fin de l’entretien, que voulez-vous que le recruteur retienne ?

Trois messages suffisent.

Exemple :

- expérience du management ;
- capacité à structurer ;
- connaissance du marché.

Ces trois messages doivent guider vos réponses.

---

## 3. Vérifiez votre pitch

Votre réponse à « Parlez-moi de vous » doit être prête.

Mais ne l’apprenez pas mot pour mot.

Vérifiez seulement :

- votre point de départ ;
- les deux ou trois étapes importantes ;
- votre conclusion ;
- le lien avec le poste.

---

## 4. Préparez cinq à huit exemples

Vous n’avez pas besoin de vingt histoires.

Préparez quelques situations solides :

- réussite ;
- échec ;
- conflit ;
- changement ;
- décision ;
- pression ;
- leadership ;
- négociation.

Ces exemples pourront être réutilisés dans plusieurs questions.

---

## 5. Reprenez vos points faibles

La veille est le bon moment pour vérifier que vous savez répondre sur :

- manque d’expérience ;
- reconversion ;
- période sans emploi ;
- faible expérience managériale ;
- compétence absente ;
- changement fréquent de poste.

Préparez une réponse :

- honnête ;
- courte ;
- structurée ;
- orientée vers les éléments compensatoires.

---

## 6. Vérifiez ce que vous savez de l’entreprise

Vous devriez pouvoir répondre clairement à :

- que fait l’entreprise ?
- qui sont ses clients ?
- quels sont ses principaux enjeux ?
- quelle actualité récente semble importante ?
- pourquoi cette entreprise vous intéresse ?

Si vous n’êtes pas capable de répondre simplement, retravaillez uniquement ces points.

---

## 7. Préparez vos questions au recruteur

Ayez plusieurs questions prêtes.

Par exemple :

- quelles seront les priorités du poste ?
- quels sont les principaux défis ?
- pourquoi le poste est-il ouvert ?
- comment sera évaluée la réussite ?
- comment l’équipe est-elle organisée ?

Préparez-en plus que vous n’en poserez.

---

## 8. Vérifiez la rémunération si le sujet peut arriver

Vous devez connaître :

- votre cible ;
- votre fourchette ;
- votre minimum acceptable ;
- les éléments du package qui comptent pour vous.

Ne découvrez pas votre propre position au moment où le recruteur pose la question.

---

## 9. Faites une dernière simulation courte

Pas un marathon.

Prenez trois à cinq questions.

Répondez à voix haute.

Vérifiez :

- clarté ;
- durée ;
- exemples ;
- naturel.

Puis arrêtez.

Le but est de rester fluide, pas de vous épuiser.

---

## 10. Préparez vos documents

Vérifiez que vous avez :

- CV ;
- offre d’emploi ;
- notes essentielles ;
- coordonnées du recruteur ;
- adresse ;
- lien de visioconférence.

Pour un entretien sur place, imprimez éventuellement un exemplaire du CV.

---

## 11. Vérifiez votre trajet

Pour un entretien physique :

- adresse exacte ;
- temps de trajet ;
- trafic ;
- transports ;
- parking ;
- accès au bâtiment.

Prévoyez une marge.

Arriver vingt minutes trop tôt est plus facile à gérer qu’arriver dix minutes en retard.

---

## 12. Vérifiez votre matériel pour un entretien à distance

Testez :

- connexion ;
- caméra ;
- micro ;
- casque ;
- batterie ;
- logiciel ;
- lien de connexion.

Fermez les applications inutiles.

Coupez les notifications.

---

## 13. Préparez votre environnement

Pour une visioconférence :

- arrière-plan propre ;
- lumière correcte ;
- niveau sonore acceptable ;
- téléphone silencieux ;
- caméra à hauteur raisonnable.

Ne cherchez pas un studio professionnel.

Cherchez un environnement sans distraction.

---

## 14. Préparez votre tenue

Le meilleur choix est généralement :

> adapté au niveau de formalité de l’entreprise et du poste.

Évitez surtout d’improviser le matin même.

Préparez tout la veille.

---

## 15. Ne révisez pas jusqu’à minuit

Une heure supplémentaire de préparation apporte rarement autant qu’une bonne nuit de sommeil.

À un moment, arrêtez.

Vous n’améliorerez probablement pas votre candidature en relisant encore l’annonce à 1 h 30 du matin.

---

## Ce que le recruteur cherche réellement

Le jour de l’entretien, le recruteur ne saura pas si vous avez passé :

- trois heures ;
- six heures ;
- douze heures ;

à préparer.

Il verra surtout :

- votre clarté ;
- votre compréhension du poste ;
- vos exemples ;
- votre capacité à répondre ;
- votre motivation.

La préparation doit donc améliorer ces éléments.

Pas devenir une fin en soi.

## 16. La checklist J-1

### Poste

- [ ] Je connais les cinq attentes principales.
- [ ] J’ai identifié mes trois meilleurs arguments.
- [ ] Je connais mes principaux écarts.
- [ ] Je sais pourquoi ce poste m’intéresse.

### Entreprise

- [ ] Je sais expliquer son activité.
- [ ] Je connais ses principaux clients ou marchés.
- [ ] J’ai identifié une actualité récente.
- [ ] Je comprends au moins un enjeu important.

### Discours

- [ ] Mon pitch est prêt.
- [ ] J’ai cinq à huit situations utilisables.
- [ ] Mes points faibles sont préparés.
- [ ] Ma motivation est précise.
- [ ] Je sais expliquer pourquoi je quitte mon poste actuel.

### Questions

- [ ] J’ai préparé au moins cinq questions.
- [ ] J’ai au moins une question sur les priorités.
- [ ] J’ai une question sur les critères de réussite.

### Rémunération

- [ ] Je connais ma fourchette.
- [ ] Je connais mon minimum.
- [ ] Je sais comment formuler ma réponse.

---

## 17. La checklist logistique

### Présentiel

- [ ] adresse vérifiée ;
- [ ] trajet vérifié ;
- [ ] marge prévue ;
- [ ] nom du contact ;
- [ ] téléphone chargé.

### Distanciel

- [ ] caméra testée ;
- [ ] micro testé ;
- [ ] connexion testée ;
- [ ] lien vérifié ;
- [ ] notifications coupées ;
- [ ] arrière-plan vérifié.

---

## 18. Ce qu’il faut arrêter de faire 12 heures avant

À ce stade, évitez :

- réécrire complètement votre pitch ;
- chercher cinquante nouvelles informations ;
- apprendre de nouvelles réponses ;
- lire des dizaines de forums ;
- comparer votre profil à tous les candidats imaginaires.

Vous entrez dans une phase de consolidation.

---

## 19. Préparez une fiche unique

Votre fiche finale doit idéalement tenir sur une page.

Elle peut contenir :

### Mes trois messages

1. …
2. …
3. …

### Mes trois meilleurs exemples

1. …
2. …
3. …

### Mes deux points de vigilance

1. …
2. …

### Mes questions

1. …
2. …
3. …

Cette fiche est beaucoup plus utile que quinze pages de notes.

---

## 20. La veille au soir : faites le test du recruteur

Posez-vous cinq questions.

### Pourquoi ce candidat ?

Quels sont vos arguments ?

### Pourquoi ce poste ?

Votre réponse est-elle spécifique ?

### Pourquoi cette entreprise ?

Avez-vous autre chose qu’un discours générique ?

### Quel est le principal risque ?

Savez-vous l’expliquer ?

### Quelle preuve est la plus forte ?

Avez-vous un exemple clair ?

---

## 21. Le matin de l’entretien

Ne recommencez pas votre préparation depuis zéro.

Relisez uniquement :

- votre fiche ;
- vos trois messages ;
- vos exemples ;
- vos questions.

Puis passez à autre chose.

---

## 22. Une heure avant

Votre objectif n’est plus d’apprendre.

Vérifiez :

- logistique ;
- tenue ;
- matériel ;
- documents.

Buvez un peu d’eau.

Évitez d’arriver mentalement épuisé.

---

## 23. Dix minutes avant

Ne relisez plus tout.

Recentrez-vous sur trois choses :

> ce que l’entreprise cherche ;

> ce que vous pouvez apporter ;

> ce que vous voulez apprendre pendant l’entretien.

---

## 24. Pendant les premières minutes

Ne cherchez pas à « réussir l’entretien » immédiatement.

Concentrez-vous simplement sur :

- saluer ;
- écouter ;
- répondre à la première question.

Le reste viendra ensuite.

---

## 25. Si vous êtes très stressé

Revenez à vos repères.

Vous connaissez :

- votre parcours ;
- vos exemples ;
- votre motivation.

Vous n’avez pas besoin de connaître toutes les questions.

Une bonne préparation sert justement à vous permettre de vous adapter.

---

## 26. Après l’entretien : capturez immédiatement les informations

Même si cela dépasse légèrement les 24 heures précédentes, préparez dès maintenant votre débrief.

À la sortie, notez :

- questions posées ;
- réponses difficiles ;
- informations sur le poste ;
- points d’attention ;
- prochaines étapes.

Vous oublierez rapidement une partie des détails.

---

## 27. Le test final

Avant de considérer votre préparation terminée, vérifiez que vous savez répondre en moins de deux minutes à :

> Parlez-moi de vous.

> Pourquoi ce poste ?

> Pourquoi cette entreprise ?

> Quelle est votre principale force pour ce poste ?

> Quel est votre principal point de vigilance ?

Si ces cinq réponses sont maîtrisées, la base est solide.

## En résumé

Dans les 24 heures précédant l’entretien :

1. relisez le poste ;
2. consolidez vos trois messages ;
3. vérifiez votre pitch ;
4. préparez quelques exemples solides ;
5. reprenez vos faiblesses ;
6. vérifiez l’entreprise ;
7. préparez vos questions ;
8. sécurisez la logistique ;
9. faites une simulation courte ;
10. arrêtez de préparer suffisamment tôt.

La veille d’un entretien, votre objectif n’est plus de devenir un meilleur candidat.

Il est de faire en sorte que **le recruteur puisse voir clairement le candidat que vous êtes déjà**.
